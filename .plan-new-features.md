# NullLauncher — план новых фич (черновик, не коммитить)

Выбрано пользователем: **Анализатор крашей, Статистика игры, CurseForge, Скин-гардероб (3D), Импорт из других лаунчеров.**

## Исследование (готово)

### 3D скины — skinview3d (MIT, Three.js)
- Вендорен: `UI/vendor/skinview3d/skinview3d.bundle.js` (477KB, Three.js вшит, UMD, глобал `skinview3d`)
- Шрифт Minecraft: `UI/vendor/skinview3d/minecraft.woff2` (+ LICENSE рядом)
- API: `new skinview3d.SkinViewer({canvas, width, height, skin})`;
  - `viewer.loadSkin(url)`, `loadCape(url, {backEquipment:"elytra"})`, `loadEars(...)`
  - `viewer.background = 0x...`, `loadBackground/loadPanorama`, `fov`, `zoom`, `autoRotate`
  - `viewer.animation = new skinview3d.WalkingAnimation()` (speed, paused), `RunningAnimation`, `WaveAnimation`
  - `viewer.cameraLight.intensity`, `viewer.globalLight.intensity` (3.0 + 0.0 = без теней)
  - `viewer.nameTag` (+ шрифт Minecraft через @font-face)
- Автоопределение slim/classic по прозрачным пикселям (skinview3d умеет сам)
- Дефолтные скины скачаны: `UI/assets/skins/steve.png`, `alex.png` (оба 64×64; Steve classic 4px, Alex slim 3px)
- Офиц. шаблоны: `http://assets.mojang.com/SkinTemplates/{steve,alex}.png`
- 9 дефолтных скинов: Sunny, Kai, Makena, Steve, Alex, Zuri, Efe, Ari, Noor
- Skin URL хранится на `textures.minecraft.net/texture/<hash>` (в профиле аккаунта)

### Формат скина
- 64×64 (или legacy 64×32), две слои (inner forced opaque; outer поддерживает прозрачность)
- slim = руки 3px, classic = 4px

### Импорт из MultiMC / Prism / ATLauncher
- Структура инстанса: `instance.cfg` (INI-подобный) + `mmc-pack.json` + подпапка `minecraft/` или `.minecraft/`
- `mmc-pack.json`: `{"formatVersion":1, "components":[{"uid":"net.minecraft","version":"1.20.1"}, {"uid":"net.fabricmc.fabric-loader","version":"0.15.11"}, ...]}`
  - uid'ы: `net.minecraft`, `net.minecraftforge`, `net.fabricmc.fabric-loader`, `org.quiltmc.quilt-loader`, `net.neoforged`
- `instance.cfg` ключи: `name`, `MinMemAlloc`, `MaxMemAlloc`, `JavaPath`, `MinecraftWinWidth/Height`, `InstanceType=OneSix`
- gameRoot = `<inst>/minecraft` или `<inst>/.minecraft` (если первый нет)
- PackImport.cs уже умеет GameFolder — добавить распознавание mmc-pack.json → instances.create

### Статистика игры (валидация: Prism тоже так делает)
- Prism хранит `totalTimePlayed`, `lastTimePlayed`, `lastLaunch` (мс) — аналогично трекать у себя
- Нужно: при launch.state running → запомнить старт; при завершении/stop → прибавить длительность к instance
- Хранить в instances.json (поле playSeconds/lastPlayedAt) +, может, отдельный лог сессий для графика

### Анализатор крашей
- Crash-reports лежат в `<gameRoot>/crash-reports/crash-*.txt`, логи в `<gameRoot>/logs/latest.log`
- Prism ищет в: `crash-reports`, `logs`, gameRoot
- Парсить: заголовок ("A fatal error has been detected by the Java Runtime Environment"), мод-виновник (net.minecraftforge / "File ... mods/xxx.jar"), OutOfMemoryError → предложить RAM, exit code
