# Обновление 1.0.3: новый главный экран и Discord-статус

Обновил NullLauncher — лаунчер Minecraft для Windows 10 и 11.

Что изменилось:

- Новый главный экран: большой баннер с вашей последней сборкой, кнопка «Играть» и быстрый выбор версии прямо на главной.
- Discord Rich Presence: теперь видно, что вы в лаунчере NullLauncher, а во время игры — какую сборку и версию Minecraft вы играете. Включается в Настройках → Конфиденциальность.
- Верхняя панель с логотипом по центру и аккуратный светлый интерфейс.

Ранее в 1.0.3:

- Универсальный импорт архивов: `.mrpack`, модпаки CurseForge, сборки NullLauncher и готовые папки `.minecraft`.
- Каталог модпаков CurseForge с поиском, фильтрами и установкой в один клик.
- Обновления из GitHub Releases — ставятся только после вашего подтверждения.

Скачать для Windows: https://github.com/rusty-prdc/NullLauncher/releases/download/v1.0.3/NullLauncher-1.0.3-Setup.exe
Переносная версия и исходный код: https://github.com/rusty-prdc/NullLauncher

Мобильная версия для Android в разработке — релиза пока нет, но прогресс публикую. Запуск игры на телефоне ещё проверяется на реальных устройствах.

Подписывайтесь, чтобы не пропустить релиз Android-версии.

NullLauncher — независимый проект XPRODC, не связан с Mojang Studios или Microsoft. Для игры может потребоваться лицензия Minecraft.
